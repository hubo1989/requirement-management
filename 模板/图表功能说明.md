# Markdown查看器图表功能说明

## 功能概述

已成功为Markdown查看器增加了对以下三种图表类型的支持：

1. **Mermaid** - 流程图和时序图
2. **PlantUML** - UML图表
3. **ECharts** - 数据可视化图表

## 新增功能特性

### 1. Mermaid图表支持
- **支持的图表类型**：流程图、时序图、状态图、甘特图等
- **语法格式**：
  ````markdown
  ```mermaid
  graph TD
      A[开始] --> B{判断}
      B -->|是| C[执行]
      B -->|否| D[结束]
  ```
  ````

### 2. PlantUML图表支持
- **支持的图表类型**：用例图、类图、时序图、活动图等
- **语法格式**：
  ````markdown
  ```plantuml
  @startuml
  actor 用户
  用户 --> (登录功能)
  @enduml
  ```
  ````

### 3. ECharts图表支持
- **支持的图表类型**：柱状图、折线图、饼图、散点图等
- **语法格式**：
  ````markdown
  ```echarts
  {
    "title": {"text": "示例图表"},
    "xAxis": {"type": "category", "data": ["A", "B", "C"]},
    "yAxis": {"type": "value"},
    "series": [{"type": "bar", "data": [10, 20, 30]}]
  }
  ```
  ````

## 技术实现

### CDN资源引用
```html
<!-- Mermaid.js -->
<script src="https://cdn.jsdelivr.net/npm/mermaid@10.6.1/dist/mermaid.min.js"></script>

<!-- PlantUML -->
<script src="https://cdn.jsdelivr.net/npm/@plantuml/plantuml-encoder@1.4.0/dist/plantuml-encoder.min.js"></script>

<!-- ECharts -->
<script src="https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js"></script>
```

### 核心功能
1. **自动识别**：Markdown解析器自动识别图表代码块
2. **异步渲染**：图表内容异步加载和渲染，不阻塞页面
3. **错误处理**：提供详细的错误信息和加载状态提示
4. **主题适配**：支持深色/浅色主题切换
5. **响应式设计**：图表自适应不同屏幕尺寸

### CSS样式增强
- 图表容器样式
- 加载状态提示
- 错误信息显示
- 响应式布局支持

## 使用方法

### 1. 基本使用
在Markdown文件中使用对应的代码块语法即可自动渲染图表。

### 2. 测试文件
创建了 `图表测试示例.md` 文件，包含各种图表类型的完整示例。

### 3. 在线访问
使用以下URL格式访问带图表的Markdown文件：
```
markdown-viewer.html?file=图表测试示例.md
```

## 功能特点

### 优点
1. **零配置**：无需额外配置，开箱即用
2. **多格式支持**：支持主流图表格式
3. **主题一致**：与Markdown查看器主题完美集成
4. **错误友好**：提供清晰的错误提示和加载状态
5. **性能优化**：异步加载，不影响页面其他内容

### 注意事项
1. PlantUML需要网络连接到在线渲染服务
2. ECharts配置必须为有效的JSON格式
3. 复杂图表可能需要一定的加载时间
4. 建议使用较新版本的浏览器以获得最佳体验

## 错误处理

### 常见问题及解决方案

1. **图表不显示**
   - 检查代码块语法是否正确
   - 确认网络连接正常（特别是PlantUML）
   - 查看浏览器控制台错误信息

2. **ECharts配置错误**
   - 确保配置为有效的JSON格式
   - 检查必要的数据字段是否完整
   - 参考ECharts官方文档配置规范

3. **主题切换异常**
   - 图表会在主题切换时自动重新渲染
   - 如遇问题可刷新页面重试
