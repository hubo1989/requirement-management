- **需求名称**: 商户信息校验控制台
- **版本号**: V1.0
- **创建日期**: 2025年10月16日
- **创建人**: 产品经理
- **状态**: 待评审

---

## 1. 项目概述

### 1.1 项目背景

为提升商户信息数据校验的效率和准确性，需要开发一个专门的校验控制台系统。该系统将支持批量文件上传、实时校验、历史记录查询等功能，为运营人员提供便捷的数据校验管理工具。

### 1.2 项目目标

- 提供统一的商户信息数据校验管理平台
- 实现校验结果的可视化展示和统计分析
- 提供完整的操作日志和历史记录追踪
- 优化用户体验，提高工作效率

### 1.3 目标用户

- **主要用户**: 运营人员、数据管理员

---

## 2. 功能需求

### 2.1 核心功能模块

#### 2.1.1 数据校验功能

**功能描述**: 支持上传商户信息文件并进行数据校验

**具体需求**:

- 支持CSV格式文件上传
- 文件大小限制：最大5MB
- 显示校验进度和结果
- 校验规则包括：数据格式、必填字段、数据完整性等

**校验规则详情**:

| 校验项目 | 校验规则 | 错误级别 |
| -------- | -------- | -------- |
| 银行ID   | 非空     | 错误     |
| 商户号   | 非空     | 错误     |

#### 2.1.2 历史记录管理

**功能描述**: 查询和管理历史校验记录

**具体需求**:

- 支持多维度筛选查询（批次号、文件名、操作人、校验状态、机构银行、日期范围）
- 分页展示历史记录（每页10条，可调整）
- 支持记录的刷新和下载操作
- 显示详细的校验统计信息

**查询筛选条件**:

- 批次号：模糊查询
- 文件名：模糊查询
- 操作人：下拉选择（全部、管理员、操作员1、操作员2）
- 校验状态：下拉选择（全部、校验成功、校验失败、处理中）
- 机构银行：下拉选择（全部、中国工商银行、中国建设银行、中国农业银行、中国银行、交通银行、招商银行）
- 日期范围：起始日期-结束日期

#### 2.1.3 模版下载功能

**功能描述**: 提供标准的数据导入模版

**具体需求**:

- 提供CSV格式的标准模版
- 模版包含所有必填字段和示例数据
- 支持下载
- 模版包含字段说明和填写规范

**模版字段**:

| 字段名 | 字段类型 | 是否必填 | 说明            |
| ------ | -------- | -------- | --------------- |
| 商户号 | 文本     | 是       | 822开头的商户号 |

### 2.2 辅助功能

#### 2.2.1 统计面板

**功能描述**: 实时显示校验统计数据

**统计指标**:

- 总记录数
- 校验成功数量
- 校验失败数量
- 处理中数量

#### 2.2.2 操作日志

**功能描述**: 记录所有用户操作行为

**日志内容**:

- 操作时间
- 操作人
- 操作类型
- 操作结果
- 备注信息

## 4. 交互设计需求

### 4.1 用户操作流程

#### 4.1.1 文件上传流程

1. 点击"上传"按钮
2. 选择文件（支持多选）
3. 系统验证文件格式和大小
4. 开始上传，显示进度条
5. 上传完成，开始校验
6. 实时显示校验结果
7. 校验完成，显示统计信息

#### 4.1.2 校验逻辑

1. 根据银行ID，查找是否存在可用的查询接口，存在则进入下一步，不存在直接返回结果：“当前银行不支持校验”
2. 使用商户号到三代系统查询商户结算卡卡号
3. 根据商户结算卡卡号与银行ID，调用对应的银行校验接口，将校验结果记录，并反馈给控台展示

#### 4.1.3 历史查询流程

1. 进入历史记录页面
2. 设置筛选条件（可选）
3. 点击"查询"按钮
4. 系统返回符合条件的数据
5. 分页展示结果
6. 支持记录的刷新和下载操作

### 4.2 交互反馈

#### 4.2.1 操作反馈

- **成功操作**: 绿色提示信息
- **失败操作**: 红色错误信息
- **警告信息**: 黄色提示信息
- **加载状态**: 转圈动画+文字提示

#### 4.2.2 表单验证

- **实时验证**: 输入时即时验证
- **提交验证**: 表单提交时统一验证
- **错误提示**: 具体字段错误信息
- **成功提示**: 操作成功的确认信息
